Health Bridge

Overview
Health Bridge is a web-based platform designed to support maternal and infant care. It provides essential features such as digital health records, symptom tracking, emergency alerts, and a donation center to assist mothers during pregnancy and postnatal care.

Features
•	Digital Health Records: A centralized system for tracking maternal and infant health history.
•	Symptom Tracker: Allows mothers to record pregnancy symptoms until their next doctor visit.
•	Emergency Alerts: Provides quick access to emergency contacts and medical assistance.
•	Donation Center: Enables mothers to donate or receive essential baby items by posting and viewing donation listings.

Technology Stack
Frontend:
•	React (with Vite)
•	HTML, CSS, JavaScript
•	Tailwind CSS for styling
Backend:
•	Node.js with Express.js
•	MongoDB for database management

Installation & Setup
Prerequisites:
•	Node.js and npm installed
•	MongoDB installed or access to a cloud database
Steps:
1.	Clone the repository: 
2.	git clone https://github.com/Methma-02/Health_Bridge.git
3.	cd health-bridge
4.	Install dependencies: 
5.	npm install
6.	Set up environment variables (.env file): 
7.	MONGO_URI=mongodb+srv://healthbridge_user:1234@healthbridge.75eap.mongodb.net/healthbridge
8.	PORT=3000
9.	Start the backend server: 
10.	npm run server
11.	Navigate to the frontend directory and start the frontend: 
12.	cd frontend
13.	npm install
14.	npm run dev
15.	Open the application in the browser at http://localhost:5173

Usage
•	Sign Up/Login: Users can register and log in to access features.
•	Manage Health Records: Mothers can track their medical history.
•	Log Symptoms: Users can record symptoms and view them later.
•	Post & View Donations: Mothers can post items for donation or request needed items.
•	Emergency Assistance: Quick access to emergency contacts.
